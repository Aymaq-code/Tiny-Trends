## Features

- Modern, responsive storefront built with Next.js App Router
- Product listing with filtering, sorting, and category browsing
- New arrivals section with animated product cards
- Shopping cart with quantity management
- Google authentication for guest area access
- Supabase backend for product data
- GSAP-powered scroll and reveal animations
- Fully typed with TypeScript
- Contact form and store location map

## Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** CSS (custom, BEM-style)
- **Database:** Supabase
- **Data Fetching:** TanStack React Query
- **Animations:** GSAP + ScrollTrigger
- **Icons:** Lucide React
- **Auth:** Google OAuth
- **Deployment:** Vercel
